## 5. 差分比较规则

### 必须字节一致

- Varint。
- ChaCha20 流。
- Poly1305 标签。
- 固定 nonce 的 CC2P。
- 大端 seq/cmd。
- RSA 固定测试向量。
- REF/XXTEA 解密结果。

### 必须语义一致

- MessagePack 映射内容。
- HTTP JSON 内容。
- 配置表对象。
- 玩家存档状态。
- 业务回包和主动推送。

映射字段顺序只有在客户端或签名依赖时才要求一致。测试报告必须说明比较方式。

### 允许不同

- 加密随机 nonce。
- 当前时间。
- 随机文件名或日志时间。
- 未注入 RNG 时的随机抽样序列。
- Go 安全默认监听地址。

允许不同的字段必须先归一化，再比较其余内容。

2. MessagePack 全类型向量。
